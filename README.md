# FocusMaid v1.4

A lightweight pixel-art focus timer for Windows, featuring a cute animated maid companion.

![maid](maid.png)

## Features

- **Focus Timer** — Start and stop focus sessions with a single click.
- **Daily Tracking** — Automatically tracks and displays accumulated daily focus time.
- **Persistent Records** — Saves focus records in TXT format without losing data when the application closes.
- **Monthly Logs** — Automatically creates a new record file each month.
- **Animated Maid** — A pixel-art maid companion with expressive animations that respond to your focus progress.
- **Minimalist Interface** — Compact, lightweight, and easy to use.

## Usage

Run the executable to start. Click the focus button to begin or stop tracking.

## Data Storage

All focus records are stored as TXT files in the `data` directory.

## Requirements

- Windows 10 / 11 (64-bit)
